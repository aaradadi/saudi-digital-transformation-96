- **رمز توثيق فريد غير متكرر إطلاقاً (Guaranteed Unique Verification ID)**: بصيغة `CECQ-2026-XXXX-XXXX` مبني على ختم زمني مشفر وعدّاد تسلسلي يمنع التكرار نهائياً.

- **حل خلل إدخال البيانات في نموذج الشهادة**: تحويل شبكة الحقول إلى تخطيط متجاوب مرن (`repeat(auto-fit, minmax(240px, 1fr))`) يمنع خروج حقل "الصفة / الفئة" خارج الإطار في أي شاشة.
- **نظام كشف المتدربين وتصدير الشيت (CSV / Excel Registry)**: حفظ بيانات المتدربين (الاسم، البريد الإلكتروني، الصفة، الرمز الفريد، وقت التوثيق) مع زر تصدير مباشر لكشف إكسل بترميز UTF-8 BOM لفتحه مباشرة في Microsoft Excel لإرسال الشهادات للطلبة لاحقاً.
- **تحسين الصور للويب (Web & GitHub Optimization):** ضغط صور القادة الثلاثة من **57 ميجابايت** إلى **2.5 ميجابايت** عالية الدقة (Retina) مع الحفاظ التام على الشفافية والنقاء، مما يجعل إجمالي حجم المجلد **4.1 ميجابايت فقط**؛ لتفادي أي تنبيهات لملفات GitHub الكبيرة وضمان تحميل فوري على الهواتف واللابتوب.
- **إضافة ملف `.nojekyll`:** لضمان تعطيل محرك Jekyll على GitHub Pages وتقديم ملفات الـ CSS والـ JS مباشرة دون أي حظر.
- **مستودع Git مجهز مسبقاً (Pre-initialized Local Git Repo):** الفرع `main` جاهز للرفع الفوري بأمر واحد.

## 🚀 خطوات النشر على GitHub Pages في دقيقة واحدة:

### 1. أنشئ مستودعاً جديداً على موقع GitHub:
1. ادخل على [github.com/new](https://github.com/new).
2. اكتب اسم المستودع، مثلاً: `saudi-digital-transformation-v5` (أو أي اسم تفضله).
3. اجعل المستودع **Public** (عام).
4. اضغط زر **Create repository**.

### 2. ارفع المشروع بضغطة زر من التيرمينال:
انسخ الأمرين التاليين ونفّذهما في التيرمينال (مع استبدال `<username>` باسم حسابك في GitHub، و `<repo-name>` باسم المستودع):

```bash
cd "/Users/asem-arwasmac/Downloads/التحول الرقمي/saudi-digital-transformation-v5"
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

### 3. تفعيل رابط الموقع المباشر (GitHub Pages):
1. في صفحة المستودع على GitHub، ادخل على:
   **Settings (الإعدادات)** > **Pages** (من القائمة الجانبية).
2. في خانة **Branch** اختر: `main` واجعل المجلد `/(root)`.
3. اضغط **Save**.

خلال دقيقة واحدة ستظهر رسالة النجاح الخضراء مع الرابط الحي المباشر:
```text
https://<username>.github.io/<repo-name>/
```
